# Generated ArchXBench designs

Each `level-N_problem.v` is the design selected from the Codex repair loop in
[docs/archxbench-results.md](../../../docs/archxbench-results.md) (first round that passed the
official flow and synthesized in Yosys, or passed and was synthesis-inconclusive). The matching
`.notes.txt` records the selected round and the model's design notes. The problem statements and
testbenches are not copied here; see https://github.com/sureshpurini/ArchXBench (commit `0db0d0d`).
